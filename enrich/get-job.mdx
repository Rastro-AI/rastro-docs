---
title: 'GET Enrich Job'
api: 'GET /public/enrich/{job_id}'
---

Poll enrichment job status and retrieve results. Use this endpoint to check on async jobs and get results when complete.

```bash
curl "https://catalogapi.rastro.ai/api/public/enrich/{job_id}" \
  -H "Authorization: Bearer rastro_pk_..."
```

## Response (Running)

While the job is processing:

```json
{
  "job_id": "abc123-def456-...",
  "results": [],
  "total_items": 10,
  "successful": 0,
  "credits_used": 0,
  "status": "running"
}
```

## Response (Completed)

When the job finishes:

```json
{
  "job_id": "abc123-def456-...",
  "results": [
    {
      "original_data": {"name": "iPhone 15 Pro"},
      "enriched_fields": {
        "price": {
          "value": "$999",
          "sources": ["https://apple.com/shop/buy-iphone/iphone-15-pro"]
        },
        "weight": {
          "value": "187 grams",
          "sources": ["https://apple.com/iphone-15-pro/specs"]
        }
      },
      "all_sources": ["https://apple.com/..."],
      "staged_change_id": "ghi789-..."
    }
  ],
  "total_items": 1,
  "successful": 1,
  "credits_used": 1,
  "status": "completed"
}
```

## Status Values

| Status | Description |
|--------|-------------|
| `running` | Job is still processing |
| `pending_review` | Job finished, results staged for review |
| `failed` | Job failed - check activity logs for details |

## Response Fields

| Field | Type | Description |
|-------|------|-------------|
| `job_id` | string | The job ID you requested |
| `results` | array | Enrichment results (empty while running) |
| `total_items` | integer | Total number of items being processed |
| `total_rows` | integer | Original total items (before any `max_rows` limit) |
| `successful` | integer | Number of successfully enriched items |
| `credits_used` | integer | Number of credits used |
| `status` | string | Current job status |

## Polling Pattern

For async enrichment jobs:

```javascript
// 1. Start enrichment with async_mode=true
const startResponse = await fetch('/api/public/enrich', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer rastro_pk_...',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    prompt: 'Find product specifications',
    items: [...],
    output_schema: [...],
    async_mode: true
  })
});
const { job_id } = await startResponse.json();

// 2. Poll until complete
let result;
while (true) {
  const pollResponse = await fetch(`/api/public/enrich/${job_id}`, {
    headers: { 'Authorization': 'Bearer rastro_pk_...' }
  });
  result = await pollResponse.json();

  if (result.status !== 'running') break;

  // Wait 2 seconds before next poll
  await new Promise(r => setTimeout(r, 2000));
}

// 3. Use results
console.log(`Enriched ${result.successful} items`);
console.log(result.results);
```

## Staged Changes

All enrichment results are stored as staged changes for review. Each result includes a `staged_change_id` which you can use with the [staged changes API](/catalogs/staged-changes) for review workflows.

Use `staged_status="draft"` when creating the job if you want vendor-only drafts (not visible to admin until submitted).

## Error Handling

If the job is not found or you don't have access:

```json
{
  "detail": "Job not found"
}
```

Status code: `404 Not Found`
