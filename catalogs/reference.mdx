## Catalog Management

### GET /public/catalogs

List all catalogs in your account.

<CodeGroup>

```python Python
response = requests.get(
    "https://catalogapi.rastro.ai/api/public/catalogs",
    headers={"Authorization": "Bearer YOUR_API_KEY"}
)
print(response.json())
```

```bash cURL
curl "https://catalogapi.rastro.ai/api/public/catalogs" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

</CodeGroup>

**Response:**

```json
{
  "catalogs": [
    {"id": "cat_123", "name": "Products", "item_count": 150}
  ]
}
```

---

<Note>
Catalogs are created through the [Rastro dashboard](https://dashboard.rastro.ai). The public API supports listing, reading, and managing items within existing catalogs.
</Note>

## Item Management

### GET /public/catalogs/{catalog_id}/items

List items in a catalog.

<CodeGroup>

```python Python
response = requests.get(
    f"https://catalogapi.rastro.ai/api/public/catalogs/{catalog_id}/items",
    headers={"Authorization": "Bearer YOUR_API_KEY"},
    params={"page": 1, "limit": 100}
)
```

```bash cURL
curl "https://catalogapi.rastro.ai/api/public/catalogs/{catalog_id}/items?page=1&limit=100" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

</CodeGroup>

**Query Parameters:**

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `page` | integer | 1 | Page number |
| `limit` | integer | 100 | Items per page (max 1000) |

**Response:**

```json
{
  "items": [
    {"id": "item_123", "sku": "A1", "title": "Product A", "price": 29.99}
  ],
  "total": 150,
  "page": 1
}
```

---

```python Python
response = requests.get(

```

```bash cURL
curl "https://catalogapi.rastro.ai/api/public/catalogs/{catalog_id}/items/{item_id}" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

</CodeGroup>

**Response:**

```json
{
  "id": "item_123",
  "sku": "A1",
  "title": "Product A",
  "price": 29.99
}
```

---

### PUT /public/catalogs/{catalog_id}/items/{item_id}

Update a single item. Only the fields you provide will be updated.

<CodeGroup>

```python Python
response = requests.put(
    f"https://catalogapi.rastro.ai/api/public/catalogs/{catalog_id}/items/{item_id}",
    headers={"Authorization": "Bearer YOUR_API_KEY"},
    json={"price": 24.99}
)
```

```bash cURL
curl -X PUT "https://catalogapi.rastro.ai/api/public/catalogs/{catalog_id}/items/{item_id}" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"price": 24.99}'
```

</CodeGroup>

**Request Body:** Any fields to update.

**Response:** The updated item.

---

### POST /public/catalogs/{catalog_id}/items/bulk

Create or update up to 1000 items at once.

<CodeGroup>

```python Python
response = requests.post(
    f"https://catalogapi.rastro.ai/api/public/catalogs/{catalog_id}/items/bulk",
    headers={"Authorization": "Bearer YOUR_API_KEY"},
    json={
        "items": [
            {"sku": "A1", "title": "Product A", "price": 29.99},
            {"sku": "A2", "title": "Product B", "price": 39.99}
        ],
        "unique_field": "sku"
    }
)
```

```bash cURL
curl -X POST "https://catalogapi.rastro.ai/api/public/catalogs/{catalog_id}/items/bulk" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "items": [
      {"sku": "A1", "title": "Product A", "price": 29.99},
      {"sku": "A2", "title": "Product B", "price": 39.99}
    ],
    "unique_field": "sku"
  }'
```

</CodeGroup>

**Request Parameters:**

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `items` | array | Yes | Array of item objects (max 1000) |
| `unique_field` | string | Yes | Field to match for upserts |

**Response:**

```json
{
  "created": 10,
  "updated": 5,
  "failed": 0
}
```

## Enriching Catalog Items

To enrich items in a catalog, use the [Enrich API](/enrich/reference) with the `catalog_id` parameter. The catalog's schema and taxonomy are automatically applied.

```python
response = requests.post(
    "https://catalogapi.rastro.ai/api/public/enrich",
    headers={"Authorization": "Bearer YOUR_API_KEY"},
    json={
        "catalog_id": "cat_abc123",
        "items": [
            {"part_number": "6205-2RS", "name": "Deep Groove Ball Bearing"}
        ],
        "speed": "slow"
    }
)
```

See [Enrich Examples](/enrich/examples#reuse-configuration-with-catalog-id) for more details.
